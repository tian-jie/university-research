# 家庭升学研究数据

这是本地文件资料库，不是填报软件或自动监测服务。更新起始日：2026-11-04。

跨session研究入口：[分阶段计划](../PLAN.md)、[当前进度与下一任务](../STATUS.md)。下文计数为既有阶段快照，后续以实际CSV和校验为准。

## 六类表

| 表 | 内容与边界 |
| --- | --- |
| [sources.csv](sources.csv) | 来源总登记；全局来源ID、旧文档编号映射、日期、适用范围、核验状态与限制。网页URL可能变化，归档另记 |
| [private/profile.csv](../private/profile.csv) | 家长提供的条件及偏好反馈；与公开资料分开，不存身份凭证。未知分数和人数留空 |
| [admissions.csv](admissions.csv) | 已有22,269条：2024与2026辽宁普通本科物理专业投档记录22,252条，另保留原17条学校录取样本；不同统计口径不混用 |
| [programmes.csv](programmes.csv) | 19条通识专业分析，另有上科大物理与化学的3条学校培养核查记录；具体范围见每条证据栏 |
| [pathways.csv](pathways.csv) | 渠道规则、资格与日程；一行一个事项。2026截止日期均为历史样本，不生成当前待办 |
| [decisions.csv](decisions.csv) | 保存研究建议、流程选择及家庭确认状态；研究建议不冒充家庭报考决定 |

`source_ids`和旧编号`aliases`用竖线分隔多个值。表格为UTF-8 CSV，可用Excel“从文本/CSV”导入，选择UTF-8；学校、专业和组代码须按文本导入，避免丢失前导零。空值表示缺失，不等于0或不适用；原因放状态或备注。数值只存数值，统计口径另列。仅学校或组投档线不能填成具体专业录取最低线。

`record_kind=fact`只用于指定来源和适用年度内核实的陈述；`analysis`和`recommendation`属于研究概括或建议；`pending`表示仍需核实。来源是本项目文档不意味着获得了独立官方证据。专业课程、去向和就业条件不因有来源ID就全部升级为已核实。

日期采用YYYY-MM-DD，时间戳使用UTC ISO 8601。`recorded_on`是入库记录日期，`published_on`是资料发布日期，`retrieved_on`是此前实际查阅日期；新下载时间在归档清单中独立记录。不能用下载日冒充发布日期。准确日未知时留空，不以报名开始日推定简章发布日期。

## 原始资料归档

下载后的原始资料保存在`raw/来源ID/抓取时间.扩展名`。`raw/manifest.jsonl`逐行保存来源ID、请求及最终URL、实际下载时间、HTTP状态、文件路径、大小和SHA-256。再次下载生成新文件并追加清单，不覆盖旧版本。

首批已归档5份：辽宁本科选科要求XLSX、选科公告、2026志愿问答、大工2026强基简章、上科大2026本科招生问答。实际文件位置与下载时刻见[归档清单](../raw/manifest.jsonl)。选科XLSX已解析48,044条本科原始行，其中46,605条符合物化生选科要求；详见[结果说明](../SUBJECT_REQUIREMENTS.md)。

只按明确登记的公开官方链接归档个人研究所需资料，不抓登录信息，不绕过网站限制，不批量转载。HTML是服务器响应原件，不是完整浏览器快照；动态站点可能只有页面外壳，归档成功不等于正文已核实。XLSX会验证ZIP结构及工作簿入口，PDF检查文件标识，公开分数JS检查预期数据变量但不执行；这些检查不代替正文核实。

[全国高校首批样本](NATIONAL_SAMPLES.md)保存了西交大的实际筛选条件和人工转录表、科大辽宁历史数据及上科大两专业培养方案的重点页码。西交大入口HTML不包含筛选后的完整证据，须与转录记录及官方查询共同查看；人工转录不是第二独立官方证据。科大公开JS原件可保留页面所用数据。

[投档底表阶段说明](ADMISSION_BASE.md)记录了2024与2026全量本科物理投档数据、2025加密附件缺口、三年分数段和位次区间参考。投档最低分不等于最终录取最低分；成绩统计人数含普通类及艺体，位次计分口径仍待核实。未知精确`rank`不以区间终点代填。

另支持ZIP结构验证及OLE容器签名检查；OLE签名不保证是可读旧式Excel，2025附件实际为加密Excel包，未解密。

## 操作

使用macOS自带Ruby标准库、curl、unzip和tar，无需安装依赖。在工作区根目录运行：

```sh
ruby scripts/research_data.rb check
ruby scripts/research_data_test.rb
ruby scripts/research_data.rb archive SRC-LN-SELECT-XLSX
ruby scripts/research_data.rb backup
```

检查包括CSV字段与列数、唯一ID、日期、来源关联、非空录取记录的基本口径、过期日程误标待办、表格公式前缀及归档文件SHA-256。它不判断招生事实正确性或学校专业适合性。

投档和分数段的导入、原始XML核对与专用快照校验命令见[底表说明](ADMISSION_BASE.md)。PDF解析使用项目内固定版Node依赖，可按锁文件重装，不依赖临时目录；备份保留依赖配置与锁文件，不包含可重建的`node_modules`。

### 选科派生数据

使用Roo读取Excel，按[Gemfile](../Gemfile)安装固定依赖；当前兼容Ruby2.6及以上，实际环境和Roo版本在每次结果摘要中记录。基本六表检查与归档备份仍只用Ruby标准库。运行：

```sh
bundle install
ruby scripts/subject_requirements_test.rb
ruby scripts/subject_requirements.rb
```

默认组合为物理、化学、生物，也可用三个独立参数指定合法的3＋1＋2组合。脚本读取最新的已校验原件，保留原始行号和原文规则，在`data/derived/`下生成独立时间目录，包含全量判断、匹配子集、院校汇总和计算摘要。不同组合和不同批次结果不覆盖。

`data/derived/manifest.jsonl`逐批保存来源原件路径及SHA-256、生成时间、组合、条目数和输出文件校验值。`check`同时检查派生文件完整性、来源关联、状态计数和匹配子集一致性；`backup`包含这些派生文件及依赖定义。

每次新增数据时以新ID追加；同一对象的不同年度、不同批次、不同校区、不同项目分别保存。政策和判断变化时新增记录，在备注注明替代的旧ID，不直接覆盖历史事实。专业组代码不能单独作为跨年度对应关系，须保留组内专业组成。确有录入错误时记录纠正原因，不伪装成政策变化。

来源登记的核验状态是当前索引，可以随核验进度更新；原始响应的历次下载仍在归档清单中追加保存。记录的语义变化不可仅靠替换来源状态表达。

## 隐私与备份

`.gitignore`排除`private/`、`raw/`、`backups/`，但忽略文件不等于加密，也不会清除旧文档里的学校与成绩描述。现有两份研究文档已有家庭信息，不应直接公开。日程与决策表仍可能反映家庭情况，对外分享前逐项脱敏。

`backup`生成覆盖文档、六表、原始归档和脚本的本地压缩包，不包含其他备份或Git历史；是未加密副本，不是异地灾备。不会自动上传云端，不会设置自动任务。另存到外置盘或采用加密备份应由家庭明确决定。新资料入库后可运行一次备份，备份与原件在同一磁盘时仍有共同损坏风险。
